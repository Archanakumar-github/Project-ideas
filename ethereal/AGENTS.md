# Ethereal: notes for coding agents

Ethereal is an Expo (SDK 57) / React Native app with a web build. Read `README.md` first:
it describes the architecture, storage schema and how the web build shares a GitHub Pages
site with three other apps.

## Expo changes every SDK: check the installed version

APIs change between SDK releases. Before touching an Expo or React Native API, check the
installed package's type definitions in `node_modules/<package>/build/*.d.ts` (or the versioned
docs at https://docs.expo.dev/versions/v57.0.0/ when reachable). Notable for SDK 57:
`expo-file-system` is the object API (`File`, `Directory`, `Paths`); Reanimated is v4 and
`runOnJS` is deprecated in favour of `scheduleOnRN` from `react-native-worklets`.

## Commands

```bash
npx expo install <package>  # resolves SDK-compatible versions (offline: see expo/bundledNativeModules.json)
npm run web                 # dev server in the browser
npm run typecheck           # tsc --noEmit
npm test                    # vitest (Node 22+, uses node:sqlite)
npm run build:web           # dist/ + service worker precache (set EXPO_BASE_URL for a sub-path)
```

Run typecheck and tests before declaring any task done.

## Conventions in this project

- No Expo Router: there is one screen (`src/screens/HomeScreen.tsx`) and a stack of sheets
  driven by `src/state/ui.ts` and rendered by `src/components/SheetHost.tsx`.
- Platform splits use file suffixes: `openDriver.ts` / `openDriver.web.ts`,
  `images/store.ts` / `store.web.ts`, `lib/backupFile.ts` / `.web.ts`.
- All SQL lives in `src/db/repo.ts`; it talks only to the `SqlDriver` interface, so tests run the
  same queries on `node:sqlite`. Add schema changes as a new entry in `src/db/schema.ts`.
- Icons are imported through `src/components/icons.ts` (one file per icon keeps the bundle small).
- Web build: nothing may touch other apps' storage on the shared origin. Caches start with
  `ethereal-`, data lives in the `ethereal` IndexedDB database, and there is no localStorage.
- `ios/` and `android/` are generated by `npx expo prebuild` (Continuous Native Generation). Don't
  edit them by hand; configure native behaviour in `app.config.ts`.
